# PramaanAI

PramaanAI is an explainable AI copilot for government tender eligibility evaluation, designed to assist procurement officers in analyzing bidder submissions, verifying compliance against tender criteria, and generating transparent, auditable decision reports with human-in-the-loop review.

The platform streamlines the tender evaluation workflow by combining document intelligence, AI-assisted reasoning, and explainable eligibility analysis into a single review system. PramaanAI focuses on reducing manual effort, improving consistency in evaluations, and enabling faster procurement decision-making while maintaining accountability and traceability.

## 🖥️ Platform Preview

![PramaanAI Intake Page](./intakePage_screenshot.png)

The intake workflow allows procurement officers to initialize a new evaluation case, upload tender documents, and trigger automated AI-assisted tender parsing and eligibility extraction.

### Workflow Overview

1. Click **Create New Case** to initialize a procurement evaluation workflow.
2. Upload the tender package through the tender upload section.
3. PramaanAI automatically parses the uploaded tender document.
4. Eligibility criteria and submission validation details are extracted and displayed in real time.

The interface is designed to provide a structured, transparent, and auditable evaluation pipeline for procurement review teams.
